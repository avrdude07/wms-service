# backend-panglong

***
Dengan menggunakan multi-module projects, Anda dapat memisahkan fungsionalitas aplikasi menjadi beberapa modul terpisah. Ini membantu dalam pemeliharaan, pengembangan, dan pengujian kode yang lebih terorganisir.

+ **wms-web** 

Berisi class atau API yang digunakan untuk keperluan applikasi
+ **wms-security**

Berisi class untuk membuat fitur authentication and authorization
+ **wms-master**

Berisi class sepeti entity, repositori, service, helper dan lain-lain untuk membuat applikasi sesuai kebutuhan user
